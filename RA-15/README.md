## Research-question teaser

Many agent failures only surface under specific context configurations — particular memory states, particular retrieved evidence, particular tool-description orderings — and remain invisible to standard offline evaluation. RA-15 presents the Contextuality Auditor: a methods contribution that systematically probes production traces for context-dependent failure modes, classifies them against a taxonomy of contextuality types, and recommends targeted mitigations. This is a methods paper, not an empirical study.
