# RA-12 — Entropy-Guided Ontology Design

**Working title:** Entropy-Guided Ontology Design: A Quantitative Framework for Domain-Specific Knowledge-Graph Architecture in Enterprise Agentic Systems.

**Authors:** Thanh Luong Tuan, Abhijit Sanyal.

**Status:** `preprint`
**ETA:** Q2 2026

---

## Research-question teaser

Given an enterprise domain with known regulatory and operational structure, how should the underlying ontology be designed — depth, breadth, granularity of concept hierarchies, density of relational predicates — to minimize task-conditional entropy for the agent workloads it must serve? RA-12 introduces an entropy-guided design framework, evaluates it across five regulated industries instantiated in the FAOS platform, and demonstrates measurable downstream improvements in grounding fidelity and judge-scored task completion.
