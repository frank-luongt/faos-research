# RA-3 v6 corpus inventory

Local planning artifacts; no public release or empirical qualification.

Run `python inventory.py` from this directory (Python standard library only). The script reads the two `/workspace` checkouts and reproduces `inventory.json`, `cell-readiness.csv` and `source-locators.csv`. It hashes every mapped input. Domain grouping is a proposed manual mapping, not a clustering algorithm or a finding of independence.

`task-eligibility.csv` records the legacy task target and explicit metric-reference field, reviewed against `code/tasks.json` and the `evaluate_response` dispatcher. `expert-coverage.csv` is an unassigned requirement register: no expert names, competency endorsements, recruitment or commitments are asserted. `fact-register-template.csv` is a blank construction template, not source evidence.

The internal report is `RA-3-V6-CORPUS-FEASIBILITY-2026-11-07.md` in the Foundation-AgenticOS RA-3 paper folder. It recommends qualifying the original six domains before accepting the larger sample. All 60 candidate cells remain unqualified; zero hyperlinks from the restricted government-domain parser does not mean zero regulatory content. No external sources were fetched in this inventory.
