Paraphrase: The clinic should respond as soon as reasonably possible. If unable to respond within 30 days, it must write within that period to state when it can respond. The example distinguishes access to information from a photocopy of handwritten notes.

Limitations: This is a private-clinic PDPA example, not a rule for every Singapore public-sector provider. Thirty days is a notification trigger here, not an automatic extra 30-day extension or an unconditional completion limit.
